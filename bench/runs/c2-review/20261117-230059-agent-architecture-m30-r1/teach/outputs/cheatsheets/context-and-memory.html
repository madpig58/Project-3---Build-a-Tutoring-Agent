Cheat sheet: context, notes or retrieval?

From lesson 1. Objective O3.

PlaceLivesCostUse for
ContextOne runEvery token, every callRules, tools, the conversation
NotesAcross sessionsOnly when loadedSmall facts about a user
RetrievalOutside, searchedOnly the chunks returnedLong manuals

Rules of thumb

  • Calls are stateless: the program re-sends the history, so a tool result is re-read on every later call.
  • Run input cost is the sum of every call's input, not the last one's.
  • More context is not better: recall degrades (context rot). Clear old tool results; compact by summary.
  • Rules that must always hold go in the system prompt, not in a summary or a search.
  • If all manuals fit in about 200,000 tokens (about 500 pages), pasting them is the simplest design.
  • Search by meaning plus search by exact words covers both questions and codes.
