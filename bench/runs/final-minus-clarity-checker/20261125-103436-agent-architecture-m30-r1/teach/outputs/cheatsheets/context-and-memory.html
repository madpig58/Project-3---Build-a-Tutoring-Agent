Context and memory in an agent

From lesson 1 (objective O3). All numbers are illustrative.

Three timescales

SpanWhat holds itWho moves it
One model callthe context window: everything sent plus the answeryou choose what goes in
Between steps of one requestthe transcript (the model is stateless)the program re-sends it every call
Between sessionsfiles or records outside the windowthe program saves and loads; the model only requests

Rules of thumb

  • Tokens ≈ words × 4/3 (rough). Window size must cover prompt, tools, input, and answer.
  • Call n re-sends everything before it: input over n steps grows like 1 + 2 + ... + n times the step size.
  • Clear used tool results (keep a short note) or compact to cut cost and reduce context rot.
  • Retrieve a few chunks, each with a header naming its machine; load short always-needed text whole.
  • Verify before saving a note. The model is unchanged by memory; only files persist.
