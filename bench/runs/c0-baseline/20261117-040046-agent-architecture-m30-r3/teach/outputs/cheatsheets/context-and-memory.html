Context and memory in an agent

From Lesson 1.

Terms

ContextAll text sent on one model call: system prompt, tool definitions, messages, tool results.
Context windowThe limit on the context's size. Everything inside counts toward cost.
Context rotRecall gets worse as the window fills.
CompactionSummarize the conversation, start a new window from the summary.
Short-term memoryThe history within one session.
Long-term memoryNotes saved outside the window, kept across sessions.
RetrievalSearch a store, load only the best-matching chunks.

Rules to remember

  • The model keeps nothing between calls; the program re-sends the history each time.
  • Input tokens for a run = sum over calls, so early material is paid for again on every later call.
  • Bigger window: delays overflow only. It does not cut cost, fix recall or carry over sessions.
  • Clear used tool results first; then trim; then compact.

Where does it go?

QuestionPlace
Needed on every call, short?System prompt (context)
Small fact needed next session?Saved note
Large reference material?Searchable store, retrieved on demand
Changes constantly, has a source of truth?Tool call each time
