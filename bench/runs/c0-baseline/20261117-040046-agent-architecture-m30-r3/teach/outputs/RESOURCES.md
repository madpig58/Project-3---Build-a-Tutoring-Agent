# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a finite resource, context rot, just-in-time retrieval, compaction, structured note-taking, sub-agents. Use for: anything about what belongs in an agent's context and how to keep it small.
- [Docs: "Context windows" (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how history accumulates each turn, compaction and clearing old tool results. Use for: mechanics of the window and its limits.
- [Docs: Memory (LangChain)](https://docs.langchain.com/oss/python/concepts/memory)
  Short-term (per-thread) versus long-term (across sessions) memory in agent frameworks. Use for: vocabulary for the two kinds of memory. Page seen in search results, not opened in full.
