# Open misconception: the model runs the tools itself (M4), and remembers on its own (M3)

In quiz 0001 (submission s1) Riley described the model as opening the booking system and running three tools inside one call, and as remembering earlier sessions without help.
Riley does understand the loop's shape, that a step limit stops a stuck agent, and that the model picks tools from their descriptions.
Later lessons should separate what the model does (writes a tool request or an answer) from what the program does (runs the tool, feeds the result back, calls the model again, saves memory).

**Evidence:** quiz 0001, submission s1, items q2, q4 (M4) and q6 (M3); q1 and q3 correct.
