Context and memory in an agent

From Lesson 1.

Terms

  • Context: everything sent on one model call: system prompt, tool definitions, messages, tool results.
  • Context window: the limit on the size of the context, counted in tokens.
  • Context rot: accuracy and recall fall as the context grows.
  • Retrieval: search a library, put only the relevant passages in context.

Where information lives

PlaceLastsUse for
ContextOne session; billed every callCurrent question, current tool results
Saved notes or databaseAcross sessionsPer-user facts, e.g. training status
Searchable libraryPermanentManuals, via up-front or just-in-time retrieval

Rules

  • The model keeps nothing between calls; the program re-sends the history.
  • Input for call n = input for call n-1 + the new request + the new result.
  • Return small tool results; put the largest result as late as possible.
  • Between sessions: write a fact down, read it back. Nothing is automatic.
  • Up-front retrieval: fewer calls, cannot retry. Just-in-time: more calls, can search again.
  • Long sessions: compaction, notes, sub-agents.
