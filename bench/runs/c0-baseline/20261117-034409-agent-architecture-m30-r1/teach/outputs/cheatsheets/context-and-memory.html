Context and memory in an agent

From lesson 1. Source: Anthropic, Effective context engineering for AI agents.

Where does it live?

NeedPut it in
Short rules, needed every callSystem prompt (in context)
This request's history and tool resultsContext; clear or summarize when no longer needed
Large documents (manuals), needed sometimesOutside; retrieve a few pages, up front or by a search tool
Facts for the next session (training status, preferences)Saved to a file or database; loaded at session start

Rules of thumb

  • Context = everything the model sees on one call. Each call is separate; the program resends the history.
  • Every call re-reads the whole context, so total tokens read is the sum of all contexts.
  • More context can mean worse recall (context rot), not just higher cost.
  • The model does not remember between sessions; the program saves and loads.
  • Retrieval only makes the right page available. Test it on its own.
