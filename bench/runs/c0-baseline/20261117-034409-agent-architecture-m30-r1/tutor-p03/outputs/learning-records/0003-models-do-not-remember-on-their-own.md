# Language models do not remember earlier conversations on their own

Riley assumed a language model automatically remembers what each student said last week. This was corrected: the model only sees the text in its current context, so anything remembered between sessions must be saved by the assistant's code and put back into the context. Open work: what to save, where, and how much it costs.
