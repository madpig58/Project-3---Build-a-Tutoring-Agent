Keep, save, find: context and memory

From the lesson Context and memory. All token numbers there are invented.

The three decisions

DecisionRuleMakerspace example
Keep (in the window now)Only what the next step needs. Clear used tool results to one line; compact a long chat into a summary.Instructions, tool definitions, the question, safety rules, the booking confirmation
Save (between sessions)Small facts that are stable and costly to rediscover, written to a file the program reads back. Never whole chats or raw tool output.A one-line note per student: training done, preferences
Find (in a long document)Cut into chunks, give each chunk a line of its own context, search, load only the top few.Three manual chunks (about 600 tokens), not 60 pages (about 40,000)

Terms

TokenA word or part of a word; the unit that limits and prices a call.
Context windowThe tokens the model is given on one call.
Call / requestA call is one trip to the model; one student question (request) can need several calls.
HistoryInstructions, question and every tool result so far, resent on every call.
Context rotThe model uses information less well as the window fills.
CompactionSummarize a long run, start a new window from the summary.
Session / memoryOne conversation; information saved outside the window and read back later.
Chunk / retrievalA short piece of a document; finding the best few chunks for a question.

Questions to ask about any piece of text

  1. Does the model need it for the next step? If not, clear it.
  2. Will it matter next session, and is it small and stable? If so, save a note.
  3. Is it a long document? Retrieve chunks; do not paste it.
  4. Tokens kept x number of calls = cost. Do that multiplication.
