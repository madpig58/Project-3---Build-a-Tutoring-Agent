Context and memory in an agent

From lesson 1.

Terms

Context windowAll text the model reads for one request, plus what it writes: system prompt, tool definitions, messages, tool results, output.
TokenA small chunk of text; the unit of window size and of billing.
Context rotRecall and accuracy get worse as the token count grows.
CompactionSummarize a long conversation and continue from the summary.
Notes (agentic memory)Facts the program saves outside the window and loads in later sessions.
RetrievalFetching only the relevant pieces of a large library into the window.

Rules to remember

  • The model keeps nothing between requests; the program resends the message list each call.
  • Every call re-reads the whole history, so cost grows with each step.
  • Nothing survives a session unless the program saves it.
  • Memory tool: the model requests a file operation, your application runs it.
  • A bigger window gives room, not value.

Where does it live?

PlacePut here
WindowShort rules, the current question, recent results
Saved notesSmall facts that must survive, with no other home
Library + retrievalLarge reference text such as manuals
A tool callFast-changing facts such as the calendar

Cost of a request

Input tokens = sum, over every model call, of everything in the window at that call. Add each new tool request and result to the next call's input.
