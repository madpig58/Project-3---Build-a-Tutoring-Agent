Context and memory in an agent

From lesson 1. Objective O3.

The three places a fact can live

PlaceLastsUse for
Context (system prompt, history, tool results)One model call; the history lasts one sessionRules needed every time; the current task
Saved notes (long-term memory)Across sessions, until deletedLow-stakes facts about a student: preferences, past bookings
Retrieval (search over manuals)Stored outside; only found pieces enter the contextLarge reference text where little is needed per question

Sorting questions, in order

  1. Needed on every request? System prompt.
  2. About this student, across sessions? Saved note, loaded at session start or read by a tool.
  3. Large reference text, small piece needed? Retrieve it, ideally with a tool.
  4. Only needed for this task? Keep in history, then clear or compact.
  5. Does a stale or wrong copy cause harm? Check the real record with a tool.

Facts to remember

  • The model keeps nothing between calls or sessions; the program re-sends history and saves and loads memory.
  • Input cost of a run = the sum of each call's full input, so early content is paid for again on every call.
  • Recall tends to get worse as the context fills (context rot); a bigger window does not remove the need to choose what goes in.

Managing a long history

TechniqueWhat it doesRisk

CompactionSummarize decisions, open questions, constraints into a fresh contextOne extra model call; a summary can drop a needed detail

Memory types and write timing

  • Semantic: facts. Episodic: past experiences or examples. Procedural: rules for how to act.
  • Hot path: write during the request; available at once, adds delay. Background: write afterward; no delay, but arrives later.

Retrieval

  • Steps: chunk, index, search, place the top chunks in the context.
  • Embeddings find similar meaning; BM25 finds exact words and codes; combine them.
  • Put machine, section and page in front of each chunk.
  • Under about 200,000 tokens (roughly 500 pages), consider putting the whole text in the prompt instead.
