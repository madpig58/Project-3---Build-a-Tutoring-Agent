Context and memory in an agent

ThingLastsUse it for
Context windowOne runThe current question, recent results
RetrievalFetched per needBig documents, such as manuals
Notes (memory tool)Across sessionsFacts about a user or a long task
  • Every model call re-sends the whole context, so you pay for it each time.
  • More context is not better: recall degrades as it fills (context rot).
  • The model keeps nothing between sessions; your program must save and reload.
  • The memory tool is client-side: the model asks, your code runs the operation.
