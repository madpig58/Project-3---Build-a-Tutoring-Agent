Context and memory in an agent

Terms

  • Context: the tokens sent on one model call (system prompt, tool descriptions, history, retrieved text).
  • Context window: the most tokens one call can take.
  • Context rot: recall gets worse as the context grows.
  • Compaction: summarise the history and start a fresh context with the summary.
  • Retrieval: search a big source and put only the best chunks in the context.
  • Notes: findings written outside the window and read back later.

Where each kind of information lives

InformationWhere
Needed on every callIn the context
Big, rarely neededOutside; retrieved
Needed next sessionSaved record or notes
Changes fastA tool, checked live

Rules of thumb

  • The model keeps nothing between calls; the program resends the history.
  • Total tokens sent = the sum of every call's whole context.
  • A bigger window is not memory: it ends with the session.
  • Retrieval can fetch the wrong chunk; test it on real questions.
