Context and memory in an agent

From lesson 1.

Key facts

  • The model sees only the context of one call, and keeps nothing between calls.
  • Your program keeps the message list and re-sends all of it every call.
  • Input tokens for a request = the sum of every call's whole context.
  • Nothing carries across sessions unless you save it and load it.

Where information lives

LayerHoldsReaches the model
ContextSystem prompt, tools, chat, tool resultsIs the input
NotesSmall facts the assistant writesLoaded at start or by a tool
RetrievalLong documents by othersSearch tool returns top chunks

Cost check

Call n input = call n-1 input + model request + tool result. Total = sum over calls.

Shrink the context

  • Clear old tool results (leave a stub).
  • Compact: summarize decisions and open items.
  • Return chunks, not pages.

Do not save

Fast-changing facts such as bookings: read them live from the tool.
