# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context rot, just-in-time retrieval, compaction, note-taking and sub-agents. Use for: context, memory and long-running agents.
- [Article: "Agentic memory management" (Elastic Search Labs)](https://www.elastic.co/search-labs/blog/agentic-memory-management-elasticsearch)
  Vendor blog on short-term versus long-term memory with an implementation. Use for: an example of storing and recalling memories; read with care, it promotes a product.
- [Survey: "Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers" (Du, arXiv)](https://arxiv.org/html/2603.07670)
  Preprint taxonomy of agent memory by scope, storage and control. Use for: vocabulary and a map of the field; not peer reviewed.
