Context and memory in an agent

From lesson 1.

Rules

  • The model sees only the context window on each call: system prompt, tool definitions, messages, results.
  • The model keeps nothing between calls; the program re-sends the list every time.
  • Input cost per request = sum of the window size at every call. Early big results are paid repeatedly.
  • Bigger window is a limit, not a target: crowded context can lower accuracy (context rot).

Retrieval steps

  1. Chunk by section; prefix each with manual and section title.
  2. Index (keywords, embeddings, or both).
  3. Search; take the top few.
  4. Insert with sources.
  5. When wrong: print the retrieved chunks first.
