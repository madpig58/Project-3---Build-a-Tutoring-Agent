Context and memory in an agent

From lesson 1.

Terms

TermMeaning
Context windowAll the text the model sees in one call: system prompt, tool definitions, messages, tool results, plus its own output.
TokenA small piece of text; windows, cost and limits are counted in tokens.
Context rotRecall and accuracy get worse as the window fills.
NotesInformation saved outside the window and reloaded into a later session.
RetrievalFetching only the relevant chunks of a large store into the window, on demand.

Where does it go?

InformationPut it in
Small, needed on every callSystem prompt
Needed only for this taskMessage list
About a person, useful next visitNotes, loaded at session start
Large, a small part needed per questionIndex, retrieved by a search tool
Live fact owned by another systemA tool that reads it fresh

Cost rule

Total input = the sum of each call's whole input. Call n's input = call n-1's input + the model's last output + the new tool result. A big result is resent on every later call.

When the window fills

Clear used tool results, summarize and continue, or hand work to a sub-agent. A bigger window is capacity, not a reason to fill it.
