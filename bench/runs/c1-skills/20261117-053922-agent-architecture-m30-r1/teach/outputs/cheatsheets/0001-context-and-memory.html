Context and memory in an agent

Core facts

  • Context window: all the text the model reads on one call. The model keeps nothing between calls.
  • Between steps: the program re-sends the whole history every call, so tokens sent grow each step.
  • Between sessions: nothing is kept unless the program saves it and loads it back.
  • Retrieval: search outside the window, bring in only the top few chunks.

Keep the window small

  • Make tools return less (filter at the source).
  • Clear old tool results.
  • Compaction: summarize and restart when near the limit.
  • Cost of a loop is the sum of every call's full window, not just new text.

Retrieval checklist

  • Chunk by section; put machine name and section title in each chunk.
  • Index with keyword and/or embedding search.
  • If wrong answers appear, check search results first, not the model.
  • Saved facts go stale: record a date and decide who updates them.
